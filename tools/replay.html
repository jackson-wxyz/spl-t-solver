SPL-T Replay

Open a game to replay

Choose a JSON file written by export_game, or drop it anywhere on this page.

  1. Start a new game of SPL-T.
  2. Split the numbered blocks in the game in order, 1, 2, 3 and so on, then press the big button.
  3. Before each batch, check the game's board, score and lowest countdown match this page.

"Show" sets how many splits appear at once (up to 8). A batch also stops at the first split that makes blocks explode or fall, since the board changes after it.

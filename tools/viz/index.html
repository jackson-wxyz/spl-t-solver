SPL-T Clockwork

How a computer-found game of SPL-T outlasts every score on record: four columns of point blocks kept in a halving chain, a beam search that steers by how long a simple policy would survive, and a lot of luck in where each run wanders.

The clockwork: four pipes, one value halving down each

Every column pair is a pipe holding a stack of up to eight 2×2 clusters. A cluster is born at the top worth the current move number and is halved each time the cluster beneath it explodes and it falls one slot. Dark cells are high values; each pipe reads as a staircase that drifts down and to the right. Hover for the exact chain at any move.

The search's safety margin

The evaluation that made this possible is blunt: from every candidate position, play the hand-tuned heuristic greedily and count how many moves it survives. The chart shows that count along the final game. Greedy play alone would have died within a few hundred moves from almost any position; the search kept picking positions where that margin stayed above 200 until the board finally filled.

A full board is a healthy board

The first intuition, rewarding free space, was backwards. From move 700 on, 100 to 112 of the 128 cells are point blocks and only three to five blocks can legally be split, yet the game has over a thousand moves left. Free cells are the raw material being turned into the next cluster; everything else is the clockwork running.

How often the search overruled the heuristic

Each child of a beam node is one of the heuristic's four best-rated moves. In Josh Holder's computed games of 2022 the heuristic's first choice was played 98% of the time; here it was played 61% of the time, and in the opening less than half. The search is doing real work, not ratifying the heuristic.

Fifty runs: the same recipe, wildly different games

The search is deterministic, so a seed only adds tiny noise to the scores, yet the same setting lands anywhere from 1,440 to 1,885. Each run is a chaotic path through the opening; the width of the beam and the rollout cap shift the whole distribution, and every penalty added on top of the plain rollout length made it worse.

The beam's family tree

A beam keeps the best thirty (here) or hundred positions at every move and drops the rest. Watching which lineages survive shows the search for what it is: long stretches where every kept position descends from one ancestor a few dozen moves back, punctuated by moments where two or three lineages compete before one wins. The top chart counts how many distinct ancestors, thirty moves back, the thirty kept positions still have; the lower one draws the tree itself for a window you can slide.
